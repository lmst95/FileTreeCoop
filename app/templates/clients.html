Geräte

Der Desktop-Client läuft im Hintergrund, überwacht die eingestellten Ordner und hält den Index aktuell – ohne offenen Browser-Tab. Über ihn lässt sich aus Baum und Suche heraus auch der Ordner im Explorer öffnen.

Client einrichten

  1. Client-Ordner aus diesem Projekt auf den Zielrechner kopieren (Verzeichnis client/) und die Abhängigkeiten installieren: 
    pip install -r client/requirements.txt
  2. Client starten – beim ersten Start öffnet sich das Einstellungsfenster: 
    python -m ftc_client
  3. Dort Serveradresse () und die eigenen Anmeldedaten eintragen, auf Verbinden klicken. Der Client tauscht sie einmalig gegen einen Gerätetoken – das Passwort wird nicht gespeichert.
  4. Im Reiter Ordner je Quelle den lokalen Ordner wählen und einzeln entscheiden, ob synchronisiert und ob gehasht werden soll.
  5. Autostart im Reiter Allgemein aktivieren – dann startet der Client künftig nach der Anmeldung automatisch mit.

Ein Gerät lässt sich hier jederzeit entfernen; sein Token gilt sofort nicht mehr, ohne dass du dein Passwort ändern musst.
